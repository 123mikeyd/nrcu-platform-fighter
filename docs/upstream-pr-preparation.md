# Experimental two-fighter frontend — current-upstream review

**Draft review artifact; not merge-ready or approved for redistribution.**

Base: upstream v0.2, `25f1eda60f74803dcd5d0ea8bc0873708398868a`.
The additive migration has been extracted into an isolated branch, without
changing the original game, live deployments or the developer's original tree.

## Scope

- Optional Teknium/Turbofit Freeplay frontend: selection, device assignment,
  READY, Toy Shelf match, three-stock results, rematch and return navigation.
- Shared match-owned movement, combat, defense/status, hitstop, stock lifecycle,
  committed presentation, generated anatomical contacts and grounded jostle.
- Combat/training laboratories, collision authoring, reproducible source-derived
  attack animation, and separately identified Sparring versus repository AI.
  Stage navigation is an adaptation, not original-bot equivalence.
- The upstream home scene remains `project.godot`'s default. Other fighters,
  Story and other stages remain original-game routes, not migrated roster claims.

## Upstream integration

All 590 upstream tracked paths remain. Only four tracked files are intentionally
modified: `.gitattributes`, `export_presets.cfg`, `tools/run_all_tests.py`, and
`tools/test_run_all_tests.py`. All 137 upstream asset paths and every original
fighter, stage, projectile, scene and project setting are preserved.

The two test-runner sides were merged, retaining both evidence-directory safety
coverage and upstream discovery/nonempty assertions. The optional Web preset
preserves v0.2 Windows metadata and all its original-game JSON include filters.
It contains no deployment host configuration.

Raw-source changes were investigated rather than replacing upstream with old
assets. All seven collision profiles were regenerated from real imported meshes.
Doge and Mephisto retain generated geometry with current raw identities; changed
presenters receive authentic generator output. Teknium/Turbofit manual balance
geometry is byte-preserved and its profile/presenter chain is updated only after
proving those regenerated profiles differ solely in presenter identity.

The Teknium imported storage graph changed at exactly two material texture
`load_path` leaves, matching upstream's texture compression change to `.s3tc.ctex`.
Independent cold imports agree on the exact new graph. The runtime still rejects
material, scene-transform, hierarchy and animation tampering. The authored swing
recipe still reproduces the exact retained derived library bytes.

GGB's standalone committed presenter follows upstream's new hover and idle flap
values while retaining committed clocks. Its source and clock oracle tests failed
before the compatibility change and pass afterward. It is not a new frontend
roster entry. AI oracle fixture preservation pins now identify the reviewed v0.2
fighter; the original bot bytes and executable decision comparisons are retained.
